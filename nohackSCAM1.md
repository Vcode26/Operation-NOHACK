# Operation:NOHACK — Incident Report  
**Case ID:** ONH‑2026‑S32‑REDIRECT  
**Prepared by:** Viaan (Founder, Operation:NOHACK)  
**Date:** January 29, 2026  
**Status:** Confirmed Typosquatting + Domain Parking + SEO Spam Injection

---

## 1. Executive Summary
Operation:NOHACK investigated suspicious behavior involving the domain **south32.com**, which displayed chaotic misinformation, repeated panic‑phrases (“Sell Sell Sell”), and redirected from a typo‑trap domain (**dictionaR.com**).

The investigation confirms:

- **south32.com is NOT owned by the real South32 mining company.**
- The domain is hosted on a **U.S. spam/parking IP block**.
- The server returns a **302 redirect from fabulous.com URL forward,**, a known domain‑parking monetization service.
- The content previously displayed on the site is **auto‑generated SEO spam**, not legitimate news.
- The real South32 uses **south32.net**, not .com.

This domain is part of a **misinformation + domain parking network**, not a corporate infrastructure.
